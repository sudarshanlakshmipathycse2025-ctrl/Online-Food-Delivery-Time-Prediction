# Food Delivery Order Status Prediction

## Run the project

1. Install dependencies: `pip install -r requirements.txt`
2. Put `daily_food_delivery_orders.csv` in this folder.
3. Open `food_delivery_ml.ipynb` and run all cells. This creates `food_delivery_model.pkl`.
4. Start the demo: `streamlit run streamlit_app.py`

The Streamlit app uses the exact preprocessing and saved model pipeline produced by the notebook.
